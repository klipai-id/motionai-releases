# MotionAI — installer

Installer aplikasi MotionAI untuk Mac dan Windows. Unduh di **https://motionai.id/download/**.

- Mac: `MotionAI-Mac.dmg` (macOS 13 atau lebih baru, Apple Silicon dan Intel)
- Windows: `MotionAI-Windows-Setup.exe` (Windows 10/11, 64-bit)

Masuk dengan akun MotionAI yang sama dengan di motionai.id. Bantuan: support@motionai.id
